# Third-party notices

The portable package includes open-source components. Their license texts and attribution requirements must be shipped with the final release after the exact PyInstaller dependency inventory is produced.

Primary components:

- RapidOCR — Apache-2.0
- ONNX Runtime — MIT
- OpenCV — Apache-2.0
- Qt for Python / PySide6 — LGPL-3.0-only or GPL-2.0-only
- NumPy — BSD-3-Clause
- MSS — MIT

Before an external distribution, copy the exact license texts from the pinned wheels into the release's `licenses` directory and retain Qt/PySide6 dynamic-linking notices.
